# sich_sdt_score_visualize
since 2026.07.08

## Aim
動画を通して太陽の中心に対して同じピクセルの明るさの集合における各フレームの同ピクセルの明るさの偏差値をカラーマッピングし、ビジュアライズすること。また、その動画を出力すること。

## Flow
1. 連番画像に変換された動画が収納されているフォルダのパスを取得
2. すべてのフレーム通しての太陽の中心に対する相対位置が共通するピクセルの明るさを取得
3. それぞれの相対位置(ピクセル)の動画を通しての明るさの平均値,標準偏差を算出。
4. 全フレームの各ピクセルの偏差値を算出
5. 色分けを定義
6. カラーマップ作成
7. 動画形式で保存
